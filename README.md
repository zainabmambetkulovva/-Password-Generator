# 🔐 Password Generator

Полноценное веб-приложение для генерации безопасных паролей с использованием Web Crypto API, включающее frontend, backend и базу данных.

## 📋 Описание

Password Generator — это современное веб-приложение, которое позволяет генерировать криптографически стойкие пароли с различными настройками. Приложение использует Web Crypto API (через Node.js crypto) для обеспечения максимальной безопасности генерации паролей.

### Основные возможности

- ✨ **Генерация безопасных паролей** с использованием криптографически стойкого генератора случайных чисел
- 🔧 **Гибкие настройки**: длина от 8 до 64 символов
- 🎯 **Выбор категорий символов**: 
  - Заглавные буквы (A-Z)
  - Строчные буквы (a-z)
  - Цифры (0-9)
  - Специальные символы (!@#$%^&*...)
- 📊 **Индикатор сложности пароля** с визуальной оценкой от 0 до 100
- 📋 **Копирование в буфер обмена** одним нажатием
- 📈 **Статистика генерации** паролей
- 📜 **История генерации** с метаданными (без сохранения самих паролей)
- 🎨 **Современный адаптивный дизайн** для всех устройств
- ✅ **Валидация настроек**: невозможно сгенерировать пароль без выбора категорий

## 🛠️ Технологический стек

### Frontend
- **HTML5** — структура страницы
- **CSS3** — современный адаптивный дизайн
- **Vanilla JavaScript** — логика без фреймворков
- **Fetch API** — взаимодействие с backend

### Backend
- **Node.js** — серверная платформа
- **Express** — веб-фреймворк
- **CORS** — поддержка кросс-доменных запросов
- **dotenv** — управление переменными окружения

- **SQLite** (better-sqlite3) — легковесная встраиваемая БД

- **Важно**: сами пароли НЕ сохраняются в БД!

## 🔌 API Endpoints

### POST /api/generate
Генерация нового пароля.

**Тело запроса:**
```json
{
  "length": 16,
  "uppercase": true,
  "lowercase": true,
  "numbers": true,
  "symbols": true
}
```

**Ответ:**
```json
{
  "success": true,
  "data": {
    "password": "A9f#kL2m@Pq7xZ",
    "strength": 85,
    "length": 16,
    "id": 42
  }
}
```

### GET /api/history
Получение истории генерации паролей (последние 50).

**Параметры запроса:**
- `limit` (необязательный) — количество записей (по умолчанию 50)

**Ответ:**
```json
{
  "success": true,
  "data": [
    {
      "id": 42,
      "length": 16,
      "hasUppercase": true,
      "hasLowercase": true,
      "hasNumbers": true,
      "hasSymbols": true,
      "strengthScore": 85,
      "createdAt": "2026-10-16T01:30:00.000Z"
    }
  ]
}
```

### GET /api/statistics
Получение статистики генерации паролей.

**Ответ:**
```json
{
  "success": true,
  "data": {
    "totalGenerated": 150,
    "avgLength": 18.5,
    "avgStrength": 78.3,
    "maxStrength": 100,
    "minStrength": 45
  }
}
```

### DELETE /api/history/cleanup
Очистка старых записей (оставляет последние 1000).

**Ответ:**
```json
{
  "success": true,
  "data": {
    "deleted": 50
  }
}
```

### GET /api/health
Проверка состояния сервера.

**Ответ:**
```json
{
  "success": true,
  "data": {
    "status": "ok",
    "timestamp": "2026-10-16T01:30:00.000Z"
  }
}
```

## 🔒 Безопасность

### Генерация паролей
- Используется **Node.js crypto** модуль (аналог Web Crypto API)
- Криптографически стойкий генератор случайных чисел
- НЕ используется `Math.random()` (небезопасно для паролей)
- Алгоритм Фишера-Йейтса для перемешивания символов

### Хранение данных
- **Сами пароли НЕ сохраняются** в базе данных
- Сохраняется только SHA-256 хеш для статистики
- История содержит только метаданные (длина, настройки, дата)
- Пароли не отправляются на сервер для других целей

### Валидация
- Проверка входных данных на сервере
- Длина пароля: от 8 до 64 символов
- Обязательный выбор хотя бы одной категории символов
- Обработка ошибок на всех уровнях

### Рекомендации
- Не храните сгенерированные пароли в открытом виде
- Используйте менеджер паролей для безопасного хранения
- Генерируйте уникальные пароли для каждого сервиса
- Рекомендуемая минимальная длина: 16 символов

## 🗄️ Структура базы данных

### Таблица: password_history

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ (автоинкремент) |
| password_hash | TEXT | SHA-256 хеш пароля (для статистики) |
| length | INTEGER | Длина пароля |
| has_uppercase | INTEGER | Использованы заглавные буквы (0/1) |
| has_lowercase | INTEGER | Использованы строчные буквы (0/1) |
| has_numbers | INTEGER | Использованы цифры (0/1) |
| has_symbols | INTEGER | Использованы спецсимволы (0/1) |
| strength_score | INTEGER | Оценка сложности (0-100) |
| created_at | DATETIME | Дата и время генерации |
