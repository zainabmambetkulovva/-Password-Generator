## 🔧 Что нужно сделать для запуска

### Шаг 1: Установка зависимостей
```bash
npm install
```

Это установит:
- express (веб-сервер)
- cors (поддержка CORS)
- dotenv (переменные окружения)
- better-sqlite3 (SQLite драйвер)

### Шаг 2: Инициализация базы данных
```bash
npm run init-db
```

Эта команда создаст файл `database/passwords.db` с необходимой структурой таблиц.

### Шаг 3: Запуск сервера
```bash
npm start
```

Сервер запустится на `http://localhost:3000`

### Шаг 4: Открытие приложения
Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

## 🔒 Важная информация о безопасности

### Что безопасно:
- ✅ Используется криптографически стойкий генератор (crypto модуль)
- ✅ Пароли НЕ сохраняются в базе данных
- ✅ Сохраняется только SHA-256 хеш для статистики
- ✅ НЕ используется Math.random()

### Что НЕ включено (и это правильно):
- ❌ Регистрация/авторизация (не нужна для генератора)
- ❌ Сохранение паролей в базе (нарушает безопасность)
- ❌ Отправка паролей на сервер для хранения

### Рекомендации:
- 📌 Используйте менеджер паролей для хранения сгенерированных паролей
- 📌 Генерируйте уникальный пароль для каждого сервиса
- 📌 Минимальная рекомендуемая длина: 16 символов
- 📌 Включайте все категории символов для максимальной безопасности

## 📊 Что умеет приложение

### Основные функции:
1. **Генерация паролей** от 8 до 64 символов
2. **Настройка категорий**: заглавные, строчные, цифры, символы
3. **Индикатор сложности** от 0 до 100
4. **Копирование в буфер обмена** одним кликом
5. **Статистика генерации**: количество, средняя длина, средняя сложность
6. **История генерации**: последние 50 паролей (только метаданные)

### API Endpoints:
- `POST /api/generate` - генерация пароля
- `GET /api/history` - получение истории
- `GET /api/statistics` - получение статистики
- `DELETE /api/history/cleanup` - очистка старых записей
- `GET /api/health` - проверка работоспособности
